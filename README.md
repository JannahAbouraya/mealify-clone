# 🍽️ Mealify Clone

A fully responsive recreation of the [Mealify website](https://mealify-teal.vercel.app/), built entirely from scratch using HTML and CSS.

## 🚀 Live Demo
[View the live site here](https://jannahabouraya.github.io/mealify-clone/) *(Note: This link will work once you enable GitHub Pages in your repository settings!)*

## 🎯 Motivation
As a second-year software engineering student gearing up for a frontend engineering internship this summer, I took on this project to solidify my core web development skills. Recreating a modern, polished UI like Mealify allowed me to practice structuring semantic HTML and implementing complex, responsive layouts without relying on external frameworks.

## 🛠️ Technologies Used
*   **HTML5:** Semantic markup for clear document structure and accessibility.
*   **CSS3:** Custom styling, CSS variables for theming, and responsive media queries.
*   **Flexbox & CSS Grid:** For building flexible, modern page layouts.

## ✨ Features
*   **Modern UI:** Closely mimics the original Mealify design and aesthetic.
*   **Fully Responsive:** Adapts smoothly to mobile, tablet, and desktop screens.
*   **Clean Code:** Organized CSS structure focusing on maintainability.
